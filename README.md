# HA TV Dashboard Blueprints
HA TV Dashboard • Home Assistant Blueprints 

> Really these should have been made a long time ago, but *better late than never* ¯\\_(ツ)_/¯

## Get Started

Pick a Blueprint and press button below to add to Home Assistant, or paste the raw URL into:
 **Settings → Automations & Scenes → Blueprints → Import Blueprint**.
